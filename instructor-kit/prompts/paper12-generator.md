# Prompt pack — Paper 1 & Paper 2 generators

Use for practice papers, topic tests, and homework. Always request a markscheme.

**Do not** ask Cursor to recreate real IB past-paper items from memory as “official” papers. Generate original questions in IB style.

---

## A. Single topic question set

```
Create original IB-style questions.
Course: [AA/AI] [SL/HL]
Paper: [1 non-GDC | 2 GDC]
Topic + syllabus codes: [ ]
Produce:
- 3 short questions (max 4 marks each)
- 1 medium (6–8 marks)
- 1 hard (9–12 marks) only if HL or stretch is requested
For each question include:
- command terms
- mark allocation
- full markscheme using instructor-kit/templates/markscheme.md
- calculator policy note
State assumptions about radians/degrees and rounding.
```

---

## B. Mixed topic mini-paper

```
Course: [ ]
Paper: [1|2]
Total marks: [30|40|50]
Time: [45|60|90] minutes
Topics to include: [list]
Difficulty mix: 40% routine / 40% mid / 20% demanding
Include a coversheet with instructions in IB tone.
Provide a complete markscheme and a suggested grade sketch (clearly labelled unofficial).
```

## F. GDC vs non-GDC twin questions

```
Topic: [ ]
Write a matched pair:
- Paper 1 version (exact methods)
- Paper 2 version (efficient GDC use + interpretation)
Same underlying concept; different skills emphasised.
Markschemes for both.
```

---

## Quality checklist (ask Cursor to self-check)

```
Before finalising, self-review:
- on-syllabus for stated course?
- command terms match required skill?
- marks match expected work time?
- any ambiguous diagrams/data missing?
- rounding instructions present where needed?
List any residual risks for the teacher to verify.
```
