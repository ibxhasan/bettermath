# Prompt pack — IA coach (teacher-facing)

Use these to **guide** students. Do not generate a finished IA that a student could submit as their own.

---

## A. Topic brainstorm (ethical)

```
Course: [AA/AI] [SL/HL]
Student interests: [hobbies, sports, arts, local Yokohama/Japan contexts optional]
Prior strengths: [algebra / calc / stats / modelling]
Stage: topic proposal

Give 5 exploration directions. For each provide:
- draft research question (student can edit)
- mathematical tools likely used (syllabus-linked)
- data/source plan (primary vs secondary)
- predicted challenge points
- Criterion E engagement hooks (personal, not performative)

Do NOT write sample analysis, conclusions, or polished IA text.
```

---

## B. Research question sharpening

```
Student draft RQ:
"""
[paste]
"""
Improve for IB Math IA quality:
- clarity / focus / mathematical depth / feasibility
Provide 3 sharpened RQ options and a “why this is stronger” note for each.
Warn if the RQ is too broad, too trivial, or off-course.
```

---

## C. Criteria-aligned formative feedback

```
Using instructor-kit/templates/ia-feedback.md, give formative feedback on this excerpt:
Criterion focus: [A|B|C|D|E] or all
"""
[paste student excerpt — anonymised]
"""
Rules:
- Speak to the teacher first with a scoring band estimate (unofficial)
- Then give student-facing comments that are specific and actionable
- Quote phrases to improve (max 3)
- Do not rewrite the exploration in submission-ready prose
```

---

## D. Structure / timeline coach

```
IA deadline: [date]
Current stage: [ ]
Build a week-by-week checklist for the student with:
- math milestones
- writing milestones
- teacher checkpoint questions
Keep it realistic for a full IB diploma load.
```

---

## E. Academic integrity script

```
Draft a 5-minute teacher talk for students on acceptable AI use for Math IA:
- allowed: brainstorming, clarifying concepts, code debugging help, language clarity
- not allowed: generating analysis/conclusion as their own, fabricating data, hiding assistance
Include 3 reflective questions students must answer before submission.
```

---

## F. Modelling IA health check

```
Student plans to model [situation] with [math approach].
Stress-test the plan:
- is the math commensurate with [SL/HL]?
- what data quality issues are likely?
- where will personal engagement show in decisions (not biography)?
- what would make a weak vs strong Criterion C/D?
Return a go / reshape / abandon recommendation with reasons.
```
