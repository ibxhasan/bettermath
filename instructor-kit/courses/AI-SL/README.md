# IB Math AI SL — course pack

Applications & Interpretation emphasises **modelling, technology, and context**.

## Cursor starter

```
Course: AI SL
Topic: [e.g. Voronoi / correlation / modelling with functions]
Paper: 2 (GDC) emphasis, plus some non-tech reasoning
Include real-world context suitable for international students in Japan when possible.
Provide GDC interpretation prompts, not only button sequences.
```

## Unit springboard

| Unit | Classroom angle | Demo idea |
|------|-----------------|-----------|
| Number & algebra in context | percentages, sequences in finance/growth | spreadsheet + Python compare |
| Functions & models | choosing models; residuals talk (light) | parameter sliders |
| Geometry & trig in applications | bearings, areas, 3D contexts | GeoGebra |
| Stats & prob | sampling stories; distributions used to decide | simulation (`binomial_simulation.py`) |
| Calculus for change | rates in context; numerical thinking with GDC | `derivative_viz.py` adapted to data |

## Watch-outs

- Context must stay mathematically honest (no fake precision)
- Students should interpret outputs, not only generate them
