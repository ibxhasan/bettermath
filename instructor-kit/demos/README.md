# Classroom demos

Small Python scripts you can project. Ask Cursor to adapt them to your topic.

## Run

```bash
python3 instructor-kit/demos/examples/binomial_simulation.py
python3 instructor-kit/demos/examples/derivative_viz.py
```

If a package is missing:

```bash
python3 -m pip install matplotlib numpy
```

## Prompt to extend

```
Adapt instructor-kit/demos/examples/[file] for [topic].
Keep projection-friendly fonts and add 3 teacher pause questions in comments.
```
