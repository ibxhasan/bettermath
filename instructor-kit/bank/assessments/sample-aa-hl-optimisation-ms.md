## Question

A rectangle has perimeter 20. Determine the maximum possible area. **[6 marks]**

| Marks | What is rewarded | Notes |
|------:|------------------|-------|
| M1 | Uses constraint to write length in terms of one variable | e.g. \(\ell=10-x\) |
| M1 | Forms area function \(A(x)=x(10-x)\) | equivalent forms OK |
| M1 | Differentiates: \(A'(x)=10-2x\) | |
| A1 | Solves \(A'(x)=0\) to get \(x=5\) | |
| R1 | Justifies maximum (2nd derivative or valid argument) | |
| A1 | States max area \(25\) with units optional | |

**Alternative method:** AM-GM or completing the square may earn equivalent M/A marks if reasoning is complete.

**FT:** allow follow-through on arithmetic slips after a correct method.

## Common errors
- Using \(A=xy\) with two free variables and never substituting constraint
- Declaring max with no justification
