## Learning intentions
- Students will be able to set up an optimisation model from a short context and justify a maximum/minimum using calculus.

## Success criteria
- I can define the quantity to optimise and the constraint.
- I can differentiate and solve \(f'(x)=0\).
- I can justify the nature of the stationary point and interpret the answer in context.

## Key example (board-ready)

A rectangle has perimeter \(20\). Find the maximum possible area.

Let width \(x>0\). Then length \(=10-x\), so \(A(x)=x(10-x)=10x-x^2\).  
\(A'(x)=10-2x=0 \Rightarrow x=5\).  
\(A''(x)=-2<0\) (or endpoint/check) ⇒ maximum.  
Max area \(=25\).

## Misconceptions to listen for
- Optimising the wrong quantity (perimeter instead of area)
- Forgetting domain restrictions from the context
- Solving \(A'(x)=0\) but never justifying max/min

## Differentiation
- Support: partially completed constraint table
- Core: standard rectangle + cylinder follow-up
- Challenge: justify without second derivative
- Language scaffold: “This is a maximum because…”
